Как собрать IPA файл для iPhone

📱 Способ 1: Отправить другу с Mac (Самый простой)

1
Найди друга с Mac
Любой человек с Mac и Xcode может собрать IPA
2
Отправь проект
Отправь папку TgWsIOS через Telegram/Google Drive
3
Друг открывает в Xcode
Двойной клик по TgWsIOS.xcodeproj
4
Друг нажимает Cmd + B
После сборки: Product → Archive → Export
✅ Готово! Друг получит TgWsApp.ipa и отправит тебе

🌐 Способ 2: Онлайн-сервисы (Бесплатно)

1
Создай репозиторий на GitHub
Перейди: github.com/new
2
Загрузи файлы вручную
Нажми "Upload files" и выбери все папки из TgWsIOS
3
Включи GitHub Actions
Вкладка Actions → "I understand" → Run workflow
4
Подожди 5 минут
GitHub сам соберёт IPA файл
✅ Скачай IPA из раздела Artifacts

💻 Способ 3: Арендуй Mac онлайн

1
Зарегистрируйся на MacStadium
macstadium.com — $0.99/час
2
Подключись через браузер
Mac откроется в твоем браузере
3
Открой проект в Xcode
Собери и экспортируй IPA
⚠️ Платный сервис, но можно арендовать на 1 час (~$1)
